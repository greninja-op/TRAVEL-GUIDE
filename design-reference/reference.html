Travel Guide design language

The place explains itself — the interface stays out of the way. Calm, warm, sun-readable; one accent per screen.

Open this page before any UI change. Copy values from here (:root / swatches) — never from memory or prose. This page is law where it disagrees with SPEC text, DESIGN-TOKENS.md, or Tokens.kt; rev it only on a system change (palette, type, radii, icons, motion), never for a feature.

Eight hues total, plus alpha washes of the same colors. One deep green accent; one warm highlight reserved for "you are here / playing now"; borders are hairlines, never boxes of color. No gradient anywhere.

Status taxonomy

Status is always dot (or icon) plus a word. Color never carries meaning alone — the label is mandatory.

Playing nowThe story being narrated right now. Highlight is used here and nowhere else.
Next on routeThe upcoming stop in walk mode.
QueuedWill speak after the current story. One voice at a time, always.
VisitedHeard or skipped; shows the time. Muted text weight, never a color change alone.
Closed nowHours say closed. The exterior story still plays.
MutedAudio off; queue paused. Mute is always visible on every screen.
Offline readyPack and map downloaded; full loop works with zero network.
Update availableA newer pack version exists. Highlight dot plus the word — never a badge count.

One implementation per component, reused everywhere — never rebuilt per screen. Every interactive element has default, hover, focus, pressed, and disabled states; async ones also have loading.

Icons

One family only: Lucide, from ICONS-ASSETS/system-and-ui/lucide/icons. 24px bounding box, 2px stroke, round caps and joins, unfilled, currentColor. Sizes 16 / 20 / 24 only. Never mix families, never fill, never emoji, never redraw a glyph per screen.

Icon-only controls get a 44px hit area and an accessible name (TalkBack label / aria-label). Icons sit neutral; primary colors an icon only when its control or row is active. Brand or tool marks, if ever shown, come from ICONS-ASSETS/apps-and-dashboards → developer-tools/stacks-and-languages → other suites — never homemade shapes.

Motion

Motion only on a genuine state change — narration, sheet, selection. Nothing moves on its own. Press 96% at 100ms; state changes 150ms; page and sheet 200ms. Enter with ease-out, leave with ease-in. Reduced motion freezes everything.

Copy

Plain verbs, sentence case, one job per element. The guide speaks like a calm person, never a hype machine. Name actions end to end; name consequences before destructive ones.

Empty state
No stops visited yet. Start walking — stories play as you arrive.
Error
Location is off. The guide needs it to notice where you are. Open settings, then try again.
Permission rationale (before the system dialog)
The guide uses your location to notice which places you're near. It works with no network, and your trip stays on this phone.
Action naming
Button "Download pack" produces "Downloaded". Button "Save note" produces "Saved". Never a bare "OK" or "Done".
Content honesty
"History" means sourced. "Legend" means told locally, not verified. "Fun fact" means a small interesting extra — never dressed up as history.

No fabricated numbers — no ratings, counts or stats without a real source. No placeholder hype ("Discover amazing places!"). Formats are human: "4 min walk", "0:42", "heard at 10:42", "pack v1.1.0".

Layout & hierarchy

  • Map first: the map is the home screen; pins carry the one accent state (playing) and everything else stays quiet.
  • One focal point per view, at most three levels. The player sheet holds one primary action; the map holds none but mute, which is always visible.
  • Bottom sheet for context, never for the primary task. One sheet implementation reused on map, route and history.
  • Big targets outdoors: 44px minimum, 48px for primary actions. Text: chrome never below 12px, place content 17–18px serif.
  • Sun-readable: text tiers kept at AA or better; no thin gray body text on the map; no text over imagery without a scrim.
  • Group by proximity — bigger gaps between sections (32–48) than inside cards (8–16). Cards get padding on all sides; lists get rhythm, not boxes per item.
  • Battery and permissions stay visible and honest: power mode stated in plain words, cost disclosed before it happens.

Hard rules

  • No new colors, fonts, radii or motion curves outside this page. Hover/press/tints are alpha layers, never new hexes.
  • No gradients anywhere. One shadow maximum (0 1px 3px rgba(0,0,0,.06)); no glow, no blur, no glass.
  • No emoji as icons, no filled or mixed icon families — Lucide only.
  • No decorative animation; nothing moves without a state change; reduced motion freeze is mandatory.
  • No fabricated content or numbers: every POI carries sources and its pack version; history, legend and fun fact stay labeled.
  • No surprise audio and no silent tracking: audio starts only after the user starts it; mute is always visible; background location is a separate, plain-language opt-in.
  • No dark theme in beta — this light system is the only one. No second accent, no per-screen theme tweaks.
  • No second implementation of the player, POI card, pin or list row.
