Travel Guide Design Language

The place explains itself — the interface stays quiet, tactile, and sun-readable. Built to the AirBnB Luxe & Alpine Lakeview aesthetic with sunset coral and midnight carbon.

Open this page before making ANY UI changes. Values defined in :root are the project's LAW. Never guess hexes or sizes from memory. All interactive components, pins, bottom sheets, navigation docks, and settings panels are specified here.

1. Color System

Warm luxury travel palette. Sunset coral (#FF5A36) is the brand accent; midnight carbon (#121826) provides high contrast; radiant amber (#F59E0B) highlights audio and reviews; emerald (#10B981) confirms 100% on-device privacy.

2. Status Taxonomy

Status is never communicated by color alone. A dedicated dot or icon is always paired with clear explanatory copy.

Audio Guide ReadyPack downloaded and narration queue pre-warmed for current location.
100% On-DeviceZero remote telemetry; GPS coordinates held in volatile RAM only.
Next Stop on RouteThe next POI along the active walking corridor.
Needs PermissionAndroid Notification Listener or Background GPS required for feature.
VisitedHeard or explored; archived into local trip history.

7. Vector Icons (Lucide Set)

Authentic Lucide vector icons only. Unfilled, 2px stroke, round caps/joins. Sourced directly from ICONS-ASSETS.

8. Non-Negotiable Hard Rules

  • No invented hex values outside this page. Use CSS variables or Compose tokens in Tokens.kt.
  • No tall egg-shaped filter buttons. All chips and pills must hug their content with a proportional 34dp height.
  • No blocking the user from testing: companion desk-testing location controls must allow stationary route simulation.
  • No cloud telemetry or tracking. 100% on-device pledge is verified and inviolable.
  • No improvised geometric stand-in icons. Authentic Lucide glyphs only.
  • No gray tap ripples on bottom navigation tabs. Use clean alpha pill indicators.
