Privacy & data architecture

Effective 28 September 2026 · Version 2.4.0 · Travel Guide for Android

1. Architectural overview

Travel Guide is built offline-first. The core of the app — location matching, route rendering, place search, notes, and on-device narration — runs on the phone. There is no remote user profile and no analytics backend.

2. Location

Location is used to work out which heritage stop is near you and how far it is.

  • Foreground first. GPS is sampled while the app is active to draw your position and calculate distances.
  • Ephemeral memory. Live coordinates are processed in RAM. They are not written to log files or a remote location history.
  • Separate opt-in. Background location is a distinct choice, never bundled into first launch. The app still works without it.

3. Google Maps companion & accessibility

The optional companion feature works alongside Google Maps navigation using Android’s AccessibilityService and/or NotificationListenerService.

Scope: the service is restricted to package com.google.android.apps.maps. It cannot observe, read, or interact with other applications.
  • Purpose. Read destination titles and navigation status when you start turn-by-turn directions.
  • Route reactivity. Highlight corridor landmarks while navigation is active, and stop when navigation ends.
  • Data handled. Public destination strings only — landmark names or addresses. No passwords, search boxes, payment data, or account details.
  • Revocation. Accessibility and notification access can be revoked at any time in Android Settings.

4. Storage & encryption

Visited places, notes, and preferences are stored locally in an on-device database.

  • Hardware KeyStore. Local encryption keys are managed through Android KeyStore, backed by the device’s secure element where supported.
  • Authenticated encryption. Sensitive stored values use AES-256-GCM.
  • You can erase it. A single confirmation in Settings permanently deletes the local database and notes.

5. Voice & narration

The on-device voice works offline and is the default. If you choose a cloud voice or the optional AI guide, the text you ask it to speak is sent to that provider only for that request. Those features are opt-in and can be turned off without losing the offline guide.

6. Third-party libraries & telemetry

The app does not include advertising frameworks, tracking pixels, or commercial telemetry SDKs. Maps use MapLibre Native with locally bundled style definitions and tiles.

7. Your controls

  • Export. Take your visit history, timestamps, and notes as a Markdown file whenever you want.
  • Erase. Wipe all local tables and notes from Settings.
  • Permissions. Audit and toggle location, notifications, accessibility, and notification access in Android Settings.

8. Contact & updates

If this document changes, the revision date and version number change with it. Technical questions can go to the repository maintainers.
